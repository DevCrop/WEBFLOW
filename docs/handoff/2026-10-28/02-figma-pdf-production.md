## PDF 제작·검수 순서

1. 현재 Figma를 읽어 최신 96쪽 여부와 새 사용자 수정 여부를 확인한다.
2. 필요한 내용 보완을 먼저 원본 Figma에 반영한다. Figma와 PDF 문구가 달라지지 않게 한다.
3. Figma native 다중 프레임 PDF를 우선 사용한다. 임시 export용 페이지가 필요하면 원본을 옮기지 말고 복제본만 사용하고 작업 후 정리한다.
4. 구성표→VOLUME 01→02→03 순서를 명시적으로 고정한다. 각 권별 파일과 통합본의 역할을 구분한다.
5. PDF 페이지 수·판형·헤더·푸터·한글·아이콘·이미지·표 넘침 확인.
6. 목차와 외부 링크가 실제 PDF에서 동작하는지 확인한다. Figma NODE hyperlink가 PDF 내부 링크로 자동 변환됐다고 가정하지 않는다.
7. 이미지 기반 대체 PDF를 만들면 그 사실을 표시한다. 편집 가능·텍스트 검색 가능을 근거 없이 주장하지 않는다.
8. 최종본만 stable filename으로 보관하고, export 일자·원본 버전·검수 결과를 기록한다.
9. 고객에게 전달/원본 이전/교육까지 완료된 것으로 자동 처리하지 않는다.

이전 내보내기 시 Figma screenshot URL 응답이 0byte로 저장된 적이 있다. 파일이 존재하는지만 보지 말고 실제 크기·파일 signature·렌더링을 확인한다. 0byte final-doc-qa-*.png는 재사용 금지.
