## 최신 문서 보완 기록

2026-10-28 최종 v1.3: 구성표2 / 스타일38 / 운영33 / 기술23 = 96쪽. Figma 본문 직계 콘텐츠 경계 넘침0. 원본 내용과 사용자 참고 목차의 장·절/점선/쪽번호 구조를 결합했고, 오래된 OP 참조와 범위 밖 교육 항목을 보완했다. 이전 2026-10-27 88쪽 기록은 과거 판본이다.

Figma native 고화질 내보내기로 통합96쪽과 권별38·33·23쪽을 생성했다. 전96쪽을 1400px 렌더링한 뒤 12개 연락판으로 페이지 순서·본문 배치·표·이미지·한글 표시를 검수했다. 목차와 주요 화면은 원본 브라우저에서도 확인했다. PDF 내부 GoTo 링크281개, 권별107/103/64개를 구성했다. 검색 가능한 한글 텍스트·벡터를 유지한다. Poppler의 Type3 glyph 경고가 발생했으나 렌더링은96쪽 모두 완료됐으며 확인 화면에서 대응하는 글자 잘림은 발견되지 않았다.

운영 26개 화면과 44개 번호 표시는 기존 검수 기록이다. CSV 안내는 직접 Excel 촬영이 아니라 출처를 표시한 Microsoft 공식 화면 예시다. 접수 데이터가 보이는 원본 캡처는 공개 Git에 포함하지 않는다.

인수인계 reference-code의 Node 시험 4개를 복제 패키지에서 실행해 전부 통과했다. 메타데이터 시험은 내부11개 사례를 포함한다. 로컬 DOM/VM 시험이며 운영 사이트 접수나 이메일 도착을 검증한 결과가 아니다.
