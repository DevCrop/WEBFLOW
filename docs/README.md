## 읽는 순서

- 새 작업 시작: 현재 상태 → 작업 절차 → 디자인 시스템
- 반응형 개행 수정: 디자인 시스템의 `Responsive Line Break Rule` → BR 체크리스트의 같은 페이지 기록
- publish 준비: 현재 상태의 게시 전 확인 → 작업 절차의 `Publish Gate`
- 과거 판단의 근거가 필요할 때만 분야별 감사 문서를 읽는다.

상세 감사 문서는 당시의 증거와 제한을 보존한다. 현재 기준과 충돌하면 `AGENTS.md`, 현재 상태, 작업 절차, 디자인 시스템 순서로 판단한다.
